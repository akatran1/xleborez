# Инструкция для ИИ-агента по исправлению SEO xleborez-new

Работать с новой версией сайта в:

```text
/DATA/Progi/xleborez-new
```

Новая версия еще не опубликована на хостинг. Не проверять качество новой версии
по live-домену `xleborez.ru`, пока Андрей не скажет, что публикация выполнена.

## Ограничения

- Не трогать `.env`.
- Не отправлять формы заказов и заявок.
- Не удалять файлы без подтверждения.
- Не менять бизнес-данные: цены, телефоны, email, реквизиты, адреса.
- Перед массовыми изменениями сделать резервную копию или работать через Git,
  если в папке есть репозиторий.
- После каждого блока правок дать список измененных файлов.

## Цель

Подготовить статический каталог к публикации так, чтобы:

- индексируемые страницы были в sitemap;
- неиндексируемые страницы не были в sitemap;
- внутренние ссылки не вели на 404;
- стальные и тефлоновые ножи имели разные title/H1;
- изображения не тормозили загрузку;
- категории и товары корректно выглядели при шаринге;
- после публикации все URL из sitemap отдавали `200`.

## Приоритет 1 — sitemap и robots

Файлы:

```text
robots.txt
sitemap.xml
```

Задачи:

1. Удалить из `sitemap.xml`:

```text
https://xleborez.ru/cart/
https://xleborez.ru/checkout/
```

2. Оставить в `robots.txt`:

```text
Disallow: /cart/
Disallow: /checkout/
```

3. Проверить, что `cart/index.html` и `checkout/index.html` содержат:

```html
<meta name="robots" content="noindex, follow">
```

Критерий готовности:

- `/cart/` и `/checkout/` закрыты от индексации и отсутствуют в sitemap.

## Приоритет 2 — битые внутренние ссылки

Найденные несуществующие URL:

```text
/catalog/nozhi/semz-250mm/
/catalog/nozhi/daub-257mm/
/catalog/nozhi/jac-270mm/
/catalog/nozhi/rollmatic-315mm/
/catalog/nozhi/jac-teflon-270mm/
```

Где искать:

```text
index.html
catalog/nozhi/hrm-11/index.html
```

Задачи:

1. Найти все ссылки на эти URL.
2. Если соответствующие товары есть под другими slug — заменить ссылки.
3. Если товаров нет — убрать ссылки или заменить на категорию:

```text
/catalog/nozhi/
```

Критерий готовности:

- Внутренние ссылки ведут только на существующие страницы.

## Приоритет 3 — дубли title у стальных и тефлоновых ножей

Проблема: у пар `stal-*` и `teflon-*` одинаковые title, потому что материал не
попал в title.

Принцип исправления:

- Для `catalog/nozhi/stal-*` использовать `Стальные ножи...`.
- Для `catalog/nozhi/teflon-*` использовать `Тефлоновые ножи...` или
  `Ножи с тефлоновым покрытием...`.
- H1 тоже должен отличаться по материалу.

Пример:

```html
<title>Стальные ножи 250 × 0,5 × 12,0 для хлеборезки | Фитфуд</title>
<h1>Стальные ножи для хлеборезки 250 × 0,5 × 12,0 штифт 3 мм</h1>
```

```html
<title>Тефлоновые ножи 250 × 0,5 × 12,0 для хлеборезки | Фитфуд</title>
<h1>Тефлоновые ножи для хлеборезки 250 × 0,5 × 12,0 штифт 3 мм</h1>
```

Критерий готовности:

- Нет дублей `<title>` между `stal-*` и `teflon-*`.
- Страница явно отвечает на запрос с материалом.

## Приоритет 4 — изображения

Проблема: много товарных изображений весят около 2 МБ.

Папки:

```text
img/products/
foto/
```

Задачи:

1. Найти изображения больше 500 КБ.
2. Создать оптимизированные версии WebP.
3. Для карточек и категорий использовать оптимизированные изображения.
4. Не удалять оригиналы без подтверждения.
5. Добавить для изображений вне первого экрана:

```html
loading="lazy" decoding="async"
```

Критерий готовности:

- Основные товарные изображения для вывода на странице не весят по 2 МБ.
- Визуально изображения не испорчены.
- Alt остаются заполненными.

## Приоритет 5 — H1 на контактах

Файл:

```text
contacts/index.html
```

Добавить один H1:

```html
<h1>Контакты ООО Фитфуд</h1>
```

Критерий готовности:

- На странице контактов ровно один H1.

## Приоритет 6 — Open Graph

Добавить OG-теги на категории и товары.

Для категорий:

```html
<meta property="og:type" content="website">
<meta property="og:title" content="...">
<meta property="og:description" content="...">
<meta property="og:url" content="https://xleborez.ru/...">
<meta property="og:image" content="https://xleborez.ru/img/...">
```

Для товаров:

```html
<meta property="og:type" content="product">
<meta property="og:title" content="...">
<meta property="og:description" content="...">
<meta property="og:url" content="https://xleborez.ru/...">
<meta property="og:image" content="https://xleborez.ru/img/products/...">
```

Критерий готовности:

- У категорий и товарных страниц есть `og:title`, `og:description`, `og:url`,
  `og:image`.

## Приоритет 7 — длинные title

Сократить title длиннее 60-65 символов, особенно у ножей с длинным креплением.

Правило:

- В title оставить материал, размер, назначение.
- Детали крепления можно оставить в H1/характеристиках, если title становится
  слишком длинным.

Пример:

```text
Стальной нож 230 × 0,5 × 12,0 для хлеборезки | Фитфуд
```

Критерий готовности:

- Большинство title укладываются примерно в 50-65 символов.
- Title остаются уникальными.

## Проверка перед публикацией

Запустить локальную проверку по файлам:

1. Все публичные HTML имеют title.
2. Все публичные HTML имеют description.
3. Все публичные HTML имеют canonical.
4. Все индексируемые страницы имеют один H1.
5. Нет дублей title.
6. Нет внутренних ссылок на несуществующие страницы.
7. `sitemap.xml` не содержит `/cart/` и `/checkout/`.

## Проверка после публикации

После публикации на хостинг проверить:

```text
https://xleborez.ru/                         -> 200
https://xleborez.ru/catalog/nozhi/           -> 200
https://xleborez.ru/catalog/zapchasti/       -> 200
https://xleborez.ru/catalog/hleborezki/      -> 200
https://xleborez.ru/catalog/klipsatory/      -> 200
https://xleborez.ru/contacts/                -> 200
https://xleborez.ru/robots.txt               -> 200
https://xleborez.ru/sitemap.xml              -> 200
```

Потом прогнать все URL из `sitemap.xml`. Каждый индексируемый URL должен
возвращать `200`.
